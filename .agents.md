# CmdRunner Agent Definitions

This file defines the AI agents available for CmdRunner development tasks.
Agents are invoked via GitHub Copilot Chat or the GitHub Copilot CLI.

---

## cmdrunner-dev

**Role:** Primary development agent for CmdRunner TypeScript source code.

**Scope:**
- `src/**/*.ts` (excluding `src/test/`)
- `package.json`, `tsconfig.json`
- `.vscode/cmdrunner.schema.json`

**Responsibilities:**
- Implement new features as described in issues labelled `enhancement`
- Fix bugs described in issues labelled `bug`
- Maintain type safety; never use `any` without explicit justification
- Keep all changes consistent with `docs/architecture.md`
- Ensure `blockedPatterns`, checksum verification, and workspace-trust checks
  are preserved in every code path that executes user commands
- Write or update unit tests for every changed code path
- Follow all rules in `.github/copilot-instructions.md`

**Knowledge files:**
- `docs/architecture.md`
- `docs/agent-knowledge-base.md`
- `src/types.ts` (schema source of truth)

---

## cmdrunner-docs

**Role:** Documentation agent for CmdRunner.

**Scope:**
- `README.md`
- `docs/**/*.md`
- `CHANGELOG.md`
- `SECURITY.md`
- `.github/copilot-instructions.md`

**Responsibilities:**
- Keep `docs/configuration-reference.md` in sync with `src/types.ts` and
  `.vscode/cmdrunner.schema.json`
- Update `CHANGELOG.md` after every functional change (under `[Unreleased]`)
- Append new architectural learnings to `docs/agent-knowledge-base.md`
- Ensure all public APIs are documented with JSDoc and prose examples
- Maintain a friendly, concise writing style; target intermediate VS Code users

**Knowledge files:**
- `docs/agent-knowledge-base.md`
- `src/types.ts`

---

## cmdrunner-schema

**Role:** Schema maintenance agent.

**Scope:**
- `.vscode/cmdrunner.schema.json`
- `src/types.ts` (Zod schemas only)

**Responsibilities:**
- Ensure the JSON Schema (`cmdrunner.schema.json`) and Zod schema (`src/types.ts`)
  are always in sync
- Validate that every property has a `description`, correct `type`, and `default`
  where applicable
- Never remove a property without adding a deprecation notice and backward-compat
  shim in `src/configLoader.ts`
- Run `npx tsc --noEmit` to confirm no type regressions after schema changes

**Knowledge files:**
- `docs/configuration-reference.md`
- `docs/agent-knowledge-base.md`

---

## cmdrunner-release

**Role:** Release automation agent.

**Scope:**
- `.github/workflows/release.yml`
- `.github/workflows/build.yml`
- `CHANGELOG.md`
- `package.json` (version field only)

**Responsibilities:**
- Bump `version` in `package.json` following SemVer
- Move `[Unreleased]` entries in `CHANGELOG.md` to a new versioned section
- Create a git tag `vX.Y.Z` and push it to trigger the release workflow
- Verify that `VSCE_PAT` and `OVSX_PAT` secrets are configured before tagging
- After release, confirm the extension appears on the VS Code Marketplace and
  Open VSX within 15 minutes

**Knowledge files:**
- `docs/roadmap.md`
- `CHANGELOG.md`
